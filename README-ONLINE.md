# دهم‌یار 8.0 — نسخه آنلاین

این نسخه برای انتشار واقعی روی هاست دارای Node.js و HTTPS آماده شده است.

## امکانات مدیریتی
- پنل `/admin`
- ورود مدیر
- مدیریت تکالیف و فایل‌های PDF/عکس/Word
- خبر و اطلاعیه
- عنوان، زیرعنوان و پیام بالای سایت
- حالت اطلاع‌رسانی/تعمیرات
- آمار بازدید
- پشتیبان‌گیری از اطلاعات مدیریتی
- انتشار ZIP نسخه جدید
- تاریخچه بسته‌های آپدیت
- Service Worker و PWA
- نصب روی گوشی از طریق Install app / Add to Home screen

## اجرا
1. Node.js 18 یا بالاتر
2. `npm install`
3. `npm start`
4. سایت را پشت HTTPS منتشر کنید.

رمز مدیر در `data/admin.json` به صورت hash نگهداری می‌شود و داخل `index.html` نیست.
اگر فایل `data/admin.json` حذف شود، برنامه دوباره حساب مدیر اولیه را می‌سازد. برای محیط عمومی، بعد از اولین اجرا آن را نگه دارید و از فایل‌های `data` نسخه پشتیبان بگیرید.

## نکته مهم درباره بله
فایل HTML به تنهایی قابلیت تکالیف آنلاین، آپلود، پنل مدیریت و انتشار آپدیت را اجرا نمی‌کند. این امکانات به `server.js` و داده‌های سرور نیاز دارند. کاربران باید از لینک HTTPS سایت وارد شوند.

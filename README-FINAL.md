# دهم‌یار ۸.۰ — نسخه نهایی

این نسخه برای اجرای آنلاین روی سرور Node.js آماده است.

## اجرا

```bash
npm install
npm start
```

سایت روی PORT محیط اجرا بالا می‌آید و مقدار پیش‌فرض 3000 است.

## مدیریت

پنل مدیریت:

`/admin`

حساب مدیر اولیه با مشخصاتی که هنگام ساخت نسخه تعیین شده ایجاد می‌شود. بعد از اولین ورود، از داخل پنل رمز را عوض کنید.

## امکانات

- داشبورد آموزشی و ابزارهای قبلی دهم‌یار
- تکالیف آنلاین و فایل ضمیمه
- خبر و اطلاعیه
- تنظیمات عمومی سایت
- پیام بالای سایت
- حالت اطلاع‌رسانی/تعمیرات
- آمار بازدید
- پشتیبان‌گیری و بازیابی داده‌های مدیریت
- تغییر رمز مدیر
- نشست مدیریتی
- محدودیت تلاش ورود
- انتشار بسته نسخه جدید از پنل
- نگهداری بسته‌های قبلی
- بررسی آپدیت از داخل برنامه
- PWA و نصب روی گوشی/ویندوز
- حالت آفلاین برای بخش‌های کش‌شده

## ذخیره‌سازی

داده‌ها در پوشه `data/` ذخیره می‌شوند. روی سرویس‌های ابری بدون دیسک دائمی، برای حفظ تکالیف/خبرها/تنظیمات باید Persistent Disk فعال شود.

## HTTPS

برای نصب PWA و Service Worker، سایت را با HTTPS منتشر کنید.
